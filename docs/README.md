# FAN Courier API Documentation

This folder contains the extracted documentation package for the FAN Courier SelfAWB integration.

## Structure

- `EN/` — English-language docs and assets
- `RO/` — Romanian-language docs and assets

## Main sections

- `EN/Integration documentation/` and `RO/API FAN Courier + FANbox/` — integration guides and API details
- `EN/Csv files/` and `RO/Fisiere csv/` — AWB CSV templates for testing and production flows
- `EN/Scripts examples/` — sample scripts and code examples
- `EN/CollectPoint and eBOX/` and `RO/CollectPoint si eBOX/` — locker and pickup-related materials

This layout makes the repository easier to browse from a local checkout or for automated agent tooling.
